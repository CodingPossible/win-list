#WIN List, a Daily Wins Tracker

Description:
Currently in development, Win List is intended to help users focus on the positive side of their to-do lists by showing only finished items at the end of the day instead of the items the uncompleted ones. 

Tech Stack:
* **Front End:** html, css, jinja
* **Back End:** Python, Flask
* **Database:** PostgreSQL

Intended base features: 
* **security** allows users to create password protected accounts
* **Daily Check-in** ability to enter to-dos and evaluate priorities at the beginning of each day
* **Daily Records** ability to quickly enter "wins" i.e. finished tasks and categorize them
* **Daily Drop** at the end of each day, unfinished to do items will be hidden so the user can focus on their 
* **History** ability to view past wins from previous days
* **goal categories** searchable by category or date, possible cross-referencing search

Hopeful "better" features:
* **future goals** Ability to enter goals for future days that will show up as options during the daily check-in
* **recurring goals** Ability to set recurring goals
* **end of day** user can pick their own end of day time 

Possible "best case" features:
* **dream bank** ability to store a master list for reference for, for example working through a project but not having to enter all of the goals at once in sub-categories, i.e. a "dream direction" or something like that
